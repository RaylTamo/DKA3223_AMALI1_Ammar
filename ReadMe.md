**HASIL ANN**
Didapati ANN mendapat testing accuracy diantara 96% - 97%.

**HASIL CNN**
Didapati CNN mendapat testing accuracy diantara 98% - 99%.

**Hasil keseluruhan**
CNN lebih sesuai untuk imej kerana ia boleh mengecam bentuk dan corak gambar dengan lebih baik, sama seperti cara mata manusia melihat. Sebaliknya, model ANN akan "meratakan" gambar menjadi satu baris nombor yang panjang, menyebabkan ia kehilangan maklumat tentang bentuk asal gambar tersebut. Oleh itu, CNN jauh lebih tepat dan berkesan berbanding ANN dalam tugas pengecaman imej.
